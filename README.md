# Investigating the Role of Regularisation Techniques for X-ray Image Recognition Models

This repository contains the code and experiments for a Master's research project evaluating the effectiveness of various regularisation methods in chest X-ray classification using CNN.

## 🔍 Techniques Evaluated
- Batch Normalisation
- L2 Regularisation
- Dropout
- Data Augmentation
- Combined Model

## 🧪 Experiments
All experiments were conducted using a transfer learning approach based on EfficientNetB0.
