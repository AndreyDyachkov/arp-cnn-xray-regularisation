# Regularisation Techniques for CNN-Based Chest X-Ray Image Classification

This repository contains the code and experiments for a Master's research project evaluating the effectiveness of various regularisation methods in chest X-ray classification using deep learning.

## 🔍 Techniques Evaluated
- Batch Normalisation
- L2 Regularisation
- Dropout
- Data Augmentation
- Combined Model

## 🧪 Experiments
All experiments were conducted using a transfer learning approach based on EfficientNetB0.
